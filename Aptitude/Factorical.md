<factorical>
factorical number is the product of all positive integers less than or equal to a given positive integer. It is denoted by n!. For example, 5! = 5 x 4 x 3 x 2 x 1 = 120.
Factorical formaul is <n! = n x (n-1) x (n-2) x (n-3) x ... x 3 x 2 x 1> 
1! = 1
2! = 2
3! = 3*2*1 = 6
4! = 4*3*2*1 = 24
5! = 120
6! = 720
7! = 5040
8! = 40320
trick to find factorical number is to multiply all the numbers from 1 to the given number.
to find 9!
8! = 40320*9
