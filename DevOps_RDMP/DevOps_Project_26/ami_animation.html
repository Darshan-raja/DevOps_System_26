📌 What is an AMI?

  • Pre-configured template for EC2 instances
  • Contains OS, applications, and configurations
  • Supports both Linux and Windows
  • Can be private, public, or shared
  • Stored in Amazon S3 (behind the scenes)

🔧 AMI Components

  • Root Volume Template (OS + Apps)
  • Launch Permissions (Who can use it)
  • Block Device Mapping (Storage)
  • Architecture (x86_64 / ARM)
  • Virtualization Type (HVM / PV)

✨ Benefits of AMI

  • Quick & consistent deployments
  • Easy horizontal scaling
  • Disaster recovery backups
  • Version control for infrastructure
  • Share configurations across teams

📋 AMI Types

  • AWS Marketplace AMIs
  • Community AMIs (Free)
  • Custom AMIs (Your own)
  • EBS-Backed AMIs
  • Instance Store-Backed AMIs
